- Ícones: lucide-react


DADOS DO APP
------------
Os dados (contas, lançamentos, etc.) ficam salvos
no armazenamento local de cada dispositivo/navegador.
Não há banco de dados em nuvem — os dados são privados
e ficam apenas no seu aparelho.


ATUALIZAR O APP NO VERCEL
--------------------------
1. Faça as alterações no código (Replit)
2. Rode o build:
   NODE_ENV=production pnpm --filter @workspace/agenda-financeira run build
3. Faça o deploy novamente com o Vercel CLI:
   vercel deploy --prebuilt --token SEU_TOKEN --yes --prod --scope danilo111727-3300s-projects
