Segue um prompt completo para a primeira tarefa:

⸻

Implementar os campos do Pedido no módulo Vendedor

Quero concluir definitivamente o fluxo do PDF de Pedido.

Hoje o sistema já gera o PDF, porém ainda faltam informações importantes que devem ser preenchidas pelo vendedor durante a venda.

Objetivo

Adicionar no módulo Vendedor todos os campos necessários para alimentar automaticamente o PDF de Pedido.

Esses campos devem fazer parte do pedido e serem salvos junto com ele.

Novos campos

Criar os seguintes campos:

Datas

* Data do pedido
    * Preencher automaticamente com a data atual.
    * Permitir edição caso necessário.
* Data prevista de entrega
    * Selecionada automaticamente pela Agenda.
    * Permitir alteração apenas quando permitido pelas regras da Agenda.

⸻

Venda

* Meio de fechamento
    * Presencial
    * WhatsApp
    * Instagram
    * Site
    * Telefone
    * Outro

⸻

Pagamento

* Forma de pagamento
    * PIX
    * Dinheiro
    * Cartão
    * Boleto
    * Transferência
* Valor de entrada
* Saldo restante
* Número de parcelas
* Observação sobre pagamento (opcional)

⸻

Responsável

* Nome do vendedor

(preenchido automaticamente pelo usuário logado, permitindo alteração apenas para administradores)

⸻

Integração com o PDF

Todas essas informações deverão aparecer automaticamente no PDF de Pedido, respeitando as configurações definidas na aba Configuração > Configuração dos PDFs.

Se o usuário desativar algum campo nas configurações do PDF, ele continua sendo salvo no pedido, porém não será exibido no documento.

Exemplo:

* Mostrar forma de pagamento → ativado → aparece no PDF.
* Mostrar forma de pagamento → desativado → continua salvo internamente, mas não aparece no documento.

O mesmo comportamento deve valer para:

* Data do pedido
* Data de entrega
* Meio de fechamento
* Forma de pagamento
* Valor de entrada
* Saldo restante
* Parcelas
* Nome do vendedor

Layout

Não criar uma nova tela.

Adicionar esses campos de forma organizada na própria aba Vendedor, preferencialmente em uma seção chamada Informações do Pedido logo acima da área Orçamento.

O fluxo deve permanecer simples e rápido.

Compatibilidade

Não alterar nenhuma funcionalidade existente.

Não quebrar o fluxo atual do Vendedor.

Não alterar a geração do PDF de Orçamento.

Implementar apenas os novos campos e integrá-los completamente ao PDF de Pedido, garantindo que tudo seja salvo junto com o pedido e utilizado automaticamente na geração do documento.
