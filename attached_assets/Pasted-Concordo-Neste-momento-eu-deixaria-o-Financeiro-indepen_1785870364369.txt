Concordo. Neste momento eu deixaria o Financeiro independente. Assim o app continua leve, mais fácil de manter e você pode integrar apenas algumas funções no futuro, se realmente fizer sentido.

Segue o prompt ajustado:

⸻

Prompt

Vamos criar uma nova aba chamada Financeiro dentro do Estofaria Digital.

IMPORTANTE: não copie a interface do aplicativo Agenda Financeira. Aproveite apenas a lógica e as funcionalidades. Toda a interface deve seguir rigorosamente o padrão visual já existente no Estofaria Digital.

Identidade visual

A nova aba deve utilizar exatamente o mesmo padrão do restante do sistema:

* mesmo cabeçalho;
* mesma barra de navegação;
* mesmas cores;
* mesmos cartões (cards);
* mesmos botões;
* mesmos espaçamentos;
* mesma tipografia;
* mesmos componentes já utilizados no app.

O usuário deve sentir que o Financeiro sempre fez parte do Estofaria Digital.

Não utilizar elementos copiados do aplicativo Agenda Financeira nem criar um layout diferente.

⸻

Aproveitar apenas a lógica

Utilizar somente a lógica do aplicativo Agenda Financeira como referência para implementar:

* contas a pagar;
* contas a receber;
* lembretes de vencimentos;
* resumo semanal;
* calendário financeiro;
* fluxo de caixa;
* histórico de movimentações;
* cadastro de entradas;
* cadastro de saídas;
* indicadores financeiros.

Toda a implementação deve ser adaptada ao padrão do Estofaria Digital.

⸻

Independência do módulo

Nesta primeira versão, o Financeiro deve ser um módulo 100% independente.

Não criar integrações automáticas com:

* Vendedor;
* Pedidos;
* Agenda;
* Produção;
* Catálogo;
* Precificação.

Todas as entradas, saídas, contas a pagar e contas a receber serão cadastradas manualmente pelo usuário.

No futuro poderão existir integrações, mas nesta etapa o foco é construir um módulo financeiro sólido, simples e leve.

⸻

Arquitetura

Reutilizar componentes existentes sempre que possível.

Não criar CSS duplicado.

Não criar novos padrões de layout.

Seguir a arquitetura atual do Estofaria Digital.

Desenvolver de forma modular para facilitar futuras expansões sem aumentar a complexidade do sistema.

⸻

Objetivo

O Financeiro deve parecer uma continuação natural do Estofaria Digital. Apenas a lógica do aplicativo Agenda Financeira servirá como inspiração. Toda a interface deve ser nativa do Estofaria Digital, mantendo o sistema leve, organizado e consistente.
