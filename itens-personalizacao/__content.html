Configuração global (vale para todos os modelos)

1. Itens de personalização

Cadastre tudo que entra no custo de personalização: tecidos, espumas, pés, acabamentos. Esses itens viram colunas na tabela de consumo.

Adicionar item

2. Álbuns de tecido

Álbuns agrupam padrões de tecido com custo fixo. Aparecem na busca do vendedor e podem ser adicionados como item na tabela de consumo.

Configuração por modelo

3. Selecionar modelo

Escolha qual modelo quer configurar. Os cards abaixo (metragens e tabela de consumo) são específicos para o modelo selecionado.

4. Metragens do modelo

Informe os tamanhos que esse modelo pode ter. Somente esses tamanhos aparecem como linhas na tabela de consumo.

Selecione um modelo acima para configurar as metragens.

5. Tabela de consumo

Para cada metragem, preencha quanto de cada item é consumido na fabricação.

Selecione um modelo acima para ver a tabela de consumo.
